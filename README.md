# S'Ena Arrubia Camping Village — Design System

Libreria del brand: logo in 5 versioni, icone (sole, pittogramma, stelle, immagini profilo),
palette, Raleway, fotografia, componenti, tutto scaricabile. Manuale in `../DESIGN.md`.

```bash
npm install
npm run dev        # libreria su http://localhost:5173
npm run build      # sito statico in dist/ (base relativa)
npm run marchio    # rigenera logo e icone dai vettoriali del cliente (richiede PyMuPDF)
```
